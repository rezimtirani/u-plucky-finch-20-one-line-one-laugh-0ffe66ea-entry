One funny line of text: my smartwatch congratulates me for standing up, then asks if I need help — because I have been sitting since 2019.

> My smartwatch congratulated me for standing up, then asked if I needed help — because I've been sitting since 2019.

## How it works

`main.py` (Python 3 standard library only) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`, checked first against the competition gate: 1 to 200 characters of UTF-8 text, a single line.

```sh
python3 main.py
```
